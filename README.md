
# Task Management and Productivity Application

A Python-based desktop application that combines task management, Pomodoro timer, and progress tracking to boost productivity.

## Features

- **Task Management**
  - Add, edit, and delete tasks
  - Set task priorities (High, Medium, Low)
  - Track deadlines
  - Mark tasks as complete/incomplete
  - SQLite database for persistent storage

- **Pomodoro Timer**
  - 30-minute work sessions
  - 7-minute short breaks
  - 20-minute long breaks after 4 sessions
  - Desktop notifications
  - Session tracking

- **Progress Tracking**
  - Visual progress charts
  - Daily task completion statistics
  - Priority-based task distribution
  - Weekly overview

- **Motivational Quotes**
  - Integration with ZenQuotes API
  - Custom fallback quotes
  - New quote after each Pomodoro session
